3. 搜尋

上傳圖片後，建議優先使用真人照片搜尋。

隱私與處理

圖片預設只在瀏覽器端處理；需要提供圖片 URL 給搜尋引擎時，Worker 只將圖片暫存於 Cloudflare KV，期限約 10 分鐘。上傳 API 只接受同源請求，並限制每個 IP 每分鐘最多 10 次上傳。
